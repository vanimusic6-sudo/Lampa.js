# CAPSULE Motion v1.0.0 — мягкие анимации для Lampa

Отдельный JS-плагин. Не требует сборки Lampa и не изменяет её файлы.

## Что изменено

Плагин работает поверх CSS Lampa и использует исходные классы и события интерфейса:

- Навигация: плавность появления экранов (`.activity`), раскрытия бокового меню (`.wrap`) и переходов между настройками.
- Карточки фильмов, сериалов и эпизодов: мягкий отклик на фокус, аккуратный масштаб и нажатие. Вместо штатного 200-мс подпрыгивания используются интерполированные трансформации.
- Модальные окна, селекторы, мобильные нижние шторки: более спокойные открытия. У закрытия свайпом сохранена продолжительность 175 мс, потому что в исходном коде Lampa логика закрытия запускается через 200 мс.
- Пункты меню, кнопки, поисковые фильтры, настройки, системная клавиатура: короткие переходы без изменения цветов и компоновки.
- TV-прокрутка: новая кривая движения при **сохранении нативных 300 мс**, поскольку внутренняя обработка Lampa привязана ко времени анимации. `notransition` / `transition-reset` не затрагиваются.
- Интерфейс плеера: анимация панели и кнопок, **без изменения видеопотока, таймлайна и механизма воспроизведения**.
- Фоновое изображение карточки: мягкое появление, без дополнительных тяжёлых фильтров.

Список базовых файлов для аудита: `src/sass/components/animation.scss`, `activitys.scss`, `scroll.scss`, `settings.scss`, `selectbox/box.scss`, `card.scss`, `wrap.scss`, `player/panel.scss`, `modal.scss`, `background.scss`; JS `src/interaction/scroll.js`, `settings/settings.js`, `select.js`, `modal.js` из [yumata/lampa-source](https://github.com/yumata/lampa-source), ветка `main`.

## Установка

1. Размести файл `CAPSULEmotion.js` по **прямой HTTPS-ссылке** (например, в отдельном файле GitHub Pages или по `raw.githubusercontent.com`).
2. В Lampa открой **Настройки → Плагины → Добавить плагин** и введи прямую ссылку на `.js`.
3. Перезапусти Lampa и открой **Настройки → CAPSULE Motion**.

> Локальный файл скачивается отдельно и не является постоянным публичным URL. Не путай адрес просмотра файла GitHub (`/blob/…`) с прямой ссылкой на содержимое (`raw.githubusercontent.com/…`).

## Настройки

- **Шёлк** — режим по умолчанию, мягкий и достаточно отзывчивый.
- **Кино** — более длительные переходы, подходит для быстрых устройств.
- **Лёгкий** — короткие, недорогие анимации для бюджетных TV и приставок.
- **Выключено** — полностью отключает действие плагина; исходная Lampa остаётся неизменной.

По отдельности можно отключить изменения **карточек**, **меню/окон** и **кнопок плеера**. По умолчанию соблюдается системный режим уменьшенного движения.

**Важно:** если в настройках самой Lampa включена опция **«Без анимаций»**, плагин её уважает и не подменяет. Для работы анимаций включи их в Lampa. Нативный флаг **«Расширенные анимации»** не обязателен.

## Совместимость и производительность

- CSS-трансформации `transform`/`opacity` + лёгкие переходы цвета, без бесконечного `requestAnimationFrame`, дорогостоящих blur/shadow анимаций, задержки кликов и изменения разметки.
- Не меняет `Lampa.Scroll` и обработчики пульта. Программная прокрутка при первом выборе и drag / touch остаются мгновенными.
- Освобождает постоянный `will-change` для карточек, чтобы не создавать лишние GPU-слои в длинных каталогах.
- Не затрагивает внутренности видеоплеера и переходы сторонних плагинов, которые используют собственные DOM-классы.
- Пункт «Лёгкий» рекомендуется для телевизоров со слабым WebView.

## Диагностика

В консоли Lampa:

```js
window.capsule_motion_runtime.status()
```

Возвращаются `preset`, `active`, `reducedMotion` и `nativeAnimationDisabled`.

Для временного удаления анимаций и очистки подписок без перезапуска:

```js
window.capsule_motion_runtime.stop()
```

Чтобы окончательно удалить плагин, удалите его URL из списка плагинов Lampa.

## Проверки

- `node --check CAPSULEmotion.js` — успешно.
- Автоматические smoke-тесты на Node (инициализация до/после `appready`, защита от повторного запуска, переключение всех параметров, reduced motion и clean-up) — успешно.
- Generated stylesheet разобран с `tinycss2` без синтаксических ошибок.

**Ограничение проверки:** без реальной сессии на вашем TV нельзя гарантировать одинаковую плавность и FPS на всех WebView. При первой установке рекомендуется проверить быстрый переход по 10–15 карточкам и шторки. Фактические FPS/визуальную совместимость на железе пока не измеряли.

## Лицензия

Плагин самостоятельно реализует CSS-адаптацию на основе публичных селекторов Lampa. Для совместимости с исходным проектом рекомендуется распространять исходный код плагина по GPL-2.0.
